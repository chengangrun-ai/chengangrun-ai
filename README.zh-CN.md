# 嗨，我是 Cami 👋

重本音乐院校毕业，却是一名全职交易员和营养师，完完全全不会写代码。

但我用 AI Agent 把「要是有人能替我干活就好了」变成了一个个真实跑起来的产品：交易平台、输入法、简历工具、拼豆图纸、相册清理、垃圾清理，都是这么来的。11 个项目 · 16 个公开仓库，代码全在里面。接下来还会继续捣鼓，希望你也一起参与。

## 🆕 最新：公子简历作坊

一份数据，四套版式，六道体检。左边填资料，中间实时变，右边告诉你这份简历机器到底读不读得懂。

不是拍脑袋定的：先把五个开源简历工具拆开量了一遍——51 份语料、3 个解析器、98 条测量，量出六种死法。最狠的是双栏版式，文字还原率 100%，字段顺序 0%。所以版式天生安全：单栏、姓名在首块、有文字层。
