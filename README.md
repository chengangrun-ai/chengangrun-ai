## 🆕 Latest: 公子简历作坊

One dataset, four layouts, six checks. Fill in the left, watch it change in the middle, and see on the right whether a machine can actually read your résumé.

Before building it I measured five open-source résumé tools — 51 samples, 3 parsers, 98 measurements — and found six ways a résumé dies. The worst: a two-column layout keeps 100% of the text but scrambles field order to 0%. So the layout is safe by construction: single column, name in the first block, a real text layer.
