# 嗨，我是 Cami 👋

**中文** · [English](#english)

重本音乐院校毕业却是一名全职交易员，完全不会写代码。

但我用 AI Agent 把「要是能自动就好了」变成真能跑的工具。

拼豆图纸、懒人编程、垃圾清理，都是这么来的。
