# 嗨，我是 Cami 👋

**中文** · [English](#english)

我做能把重复劳动变成一条命令的工具。没有传统工程背景，靠 Agent 把想法做成能跑的东西——**代码对我来说是表达的媒介，不是目的。**

把工作流开源，就是最强的 Learn in Public。

---

## ⭐ 精选项目

最常用的几个。

### 🧩 创意与设计

🧩 [pindou-gongzi](https://github.com/chengangrun-ai/pindou-gongzi) — 把任何图片变成拼豆图纸：四张成品图 + 带色号图纸 + 可直接发布的文案台账

### 🏗️ 编程工作流

🏗️ [camiai-programming-workflow](https://github.com/chengangrun-ai/camiai-programming-workflow) — 从 MVP 规划到人工验收的五步编程流程，产品设计和技术设计可按需跳过

🦥 [ponytail](https://github.com/chengangrun-ai/ponytail) — 懒人模式：任何写代码的任务先问一句「这段代码是不是根本不用写」

🔍 [ponytail-audit](https://github.com/chengangrun-ai/ponytail-audit) — 整仓过度设计审计，扫整个代码库而不是单次改动

📒 [ponytail-debt](https://github.com/chengangrun-ai/ponytail-debt) — 技术债账本，把散落在代码里的简化注释收成一张表

🃏 [ponytail-help](https://github.com/chengangrun-ai/ponytail-help) — 速查卡：全部模式、命令和切换方式一页看完

### 🔧 效率工具

🧹 [cleanup-junk](https://github.com/chengangrun-ai/cleanup-junk) — Windows 垃圾清理：先扫描出报告，确认后才动手，删除一律进回收站

⚙️ [mt5-ex5-fallback](https://github.com/chengangrun-ai/mt5-ex5-fallback) — MT5 EA 编译兜底：沙箱编不出 .ex5 时的替代路径

🔭 [agent-reach](https://github.com/chengangrun-ai/agent-reach) — 跨平台调研搜索，一次查清一个话题
