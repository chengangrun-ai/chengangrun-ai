## 🚀 怎么用

工具全部是 [Agent Skills](https://agentskills.io/specification) 格式，支持 WorkBuddy、Claude Code、Cursor、Codex 等。

```bash
npx skills add chengangrun-ai/pindou-gongzi
```

或者把仓库链接直接丢给你的 Agent，它会读 `SKILL.md` 自己上手。
